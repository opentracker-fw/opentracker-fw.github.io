3.0.0 preview

Pick your image

OpenTracker 3 comes in four flavours: the same firmware with a different set of synths and effects compiled in. The Tracker runs everything from its flash memory, so there is no room for all of them at once.

Only one image can be installed at a time. To switch, install another .ptf the same way; your projects and patches stay on the card. A project that uses a synth the image does not have still opens, but that synth shows “not available” and stays silent until you install an image that has it.

This is a preview for testing, not for real work. Back up your SD card first.

A custom image builder

A custom image builder is planned, so you can pick your own set of synths and effects and get one .ptf with exactly those.

  • Phase 1, today: build profiles in the firmware repository. A profile lists the modules an image compiles in, and the build checks that they fit in flash, memory and CPU. You can already build your own image from the source this way.
  • Phase 2: a build server that makes the image for you from a web page: coming later
